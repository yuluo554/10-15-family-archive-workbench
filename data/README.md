## 三、合成数据纪律与假名白名单

- 所有测试样例人物姓名一律取自**假名白名单**："张三丰、李四、王五、赵六、孙七、周八、吴九、郑十"式登记名，禁止真实人名、真实证件号、真实电话号、真实地址入样例。
- 如样例需证件号/电话格式字段：证件号用不可能段（如 999999 开头占位）、电话用 `19900000000` 类假号段、DOI 类引用一律用 `10.9999/` 假前缀——白名单在此登记，生成器只允许取白名单值。
- 真值纪律：真值与植入字段由生成器**单一来源**输出；注记/manifest 不手写第二份口径（口径一致性预检④）。
- 基准覆盖度口径（写入 manifest，不写硬数字）：必填缺失、词表外取值、W3CDTF 非法日期、敏感字段抹除、人物关系各类异常类型**每类至少有代表性用例**，防真值偏科。
- 数值口径一处定义：所有阈值/口径只在生成器或 profile 的数据字段中定义一次，文档引用不另写第二表述；不写随实现漂移的硬数字，数值以末态回填。
