## 1. 基准构成（模块 5）

```
合成样例生成器（benchmark.py）
  → 样例集（模拟扫描件 + 植入著录字段）
  → 真值 manifest（与植入字段同源生成，单一来源）
  → 断言脚本（famarchive benchmark / pytest）
```

- **真值单一来源**：生成器一次输出"植入字段 + 期望校验结果"，manifest 不手写第二份口径；
- **假名纪律**：人物姓名只从 data/vocabularies 假名白名单取；证件号用 `999999` 开头占位段、电话用 `19900000000` 假号段；禁止真实人名/证件号/地址入样例。

## 2. 断言清单（按异常类型覆盖度口径）

| 异常类型 | 断言内容 | 对应模块 |
|---|---|---|
| 必填缺失 | 缺必填字段的样例被拦截，且报错挂规则出处 | 模块 2 |
| 词表外取值 | type/关系边取词表外值被拦截 | 模块 2/3 |
| W3CDTF 非法日期 | 非法日期格式（如 `2026/10/14`、`去年`）被拦截；合法格式全通过 | 模块 2 |
| 敏感字段抹除 | 导出文件中 GPS/证件号字段**不出现**（非置空）；manifest 记录 profile/白名单版本 | 模块 4 |
| 人物关系 | 关系边类型受词表约束；同名人物不自动合并；未编目完成项不进年表 | 模块 3 |
| 指纹去重 | 同一文件二次导入不入库 | 模块 1 |
| EXIF 纪律 | EXIF 值只出现在预填建议，不自动出现在著录字段 | 模块 1 |

每类至少一个代表性用例（防真值偏科）；覆盖度口径写进 manifest，不写随实现漂移的硬数字，数值以末态回填。

## 3. 复跑说明（进 README）


## 4. 验收 DoD 汇总（从题目文档收敛）

- 混合媒体导入不丢件（含无 EXIF 文件）；
- 著录校验逐条可回溯出处且基准断言通过；
- 导出敏感字段确证抹除（断言"不出现"而非"置空"）；
- 录入→编目→年表→检索→导出全链路在 exe 内可达；
- profile 版本间必填/可选集实质可区分（版本化演示）；
- 发布三件套：tag + GitHub Release（产物 sha256 留档）+ plan/RELEASE-M6.md。
